# Get-SIACertificate

## SYNOPSIS
Returns details of SIA certificates

## SYNTAX

```
Get-SIACertificate [<CommonParameters>]
```

## DESCRIPTION
Returns details of TLS certificates configured in SIA to secure connections to Windows targets.

## EXAMPLES

### Example 1
```
Get-SIACertificate
```

Get details of configured TLS certificates
