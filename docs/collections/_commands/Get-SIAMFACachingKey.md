# Get-SIAMFACachingKey

## SYNOPSIS
Get the SIA SSH MFA caching key

## SYNTAX

```
Get-SIAMFACachingKey [<CommonParameters>]
```

## DESCRIPTION
Returns the MFA caching key used for SSH single sign-on with SIA.

## EXAMPLES

### Example 1
```powershell
Get-SIAMFACachingKey
```

Returns the SSH MFA caching key for the authenticated user.
