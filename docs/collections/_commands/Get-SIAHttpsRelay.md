# Get-SIAHttpsRelay

## SYNOPSIS
Get SIA HTTPS relays

## SYNTAX

```
Get-SIAHttpsRelay [<CommonParameters>]
```

## DESCRIPTION
Returns a list of the HTTPS relays configured in SIA.

## EXAMPLES

### Example 1
```powershell
Get-SIAHttpsRelay
```

Returns all configured HTTPS relays.
